# Eldar's Portfolio 🚀

A modern and dynamic developer portfolio built with **Next.js 14**, **Tailwind CSS**, **Framer Motion**, and **shadcn/ui**.

## ✨ Features

- ⚡ Built with **Next.js 14 App Router**
- 🎨 Styled with **Tailwind CSS 3.3.5**
- 🎞️ Smooth animations using **Framer Motion**
- 🧩 Beautiful components via **shadcn/ui**
- 📱 Fully responsive for mobile, tablet & desktop
- 🧠 Developer-focused clean UI
- 📄 Resume download functionality
- 🌐 SEO-friendly and fast loading

## 📁 Folder Structure

eldar_portifolio/
├── app/ # App directory (Next.js 14)
├── components/ # Reusable components (UI, animations)
├── public/ # Static assets (images, resume, etc.)
├── styles/ # Global styles
├── tailwind.config.js # Tailwind config
├── components.json # shadcn/ui config
├── README.md # You're reading it!

## 🛠️ Technologies Used

- **Next.js 14** — Full-stack React framework
- **Tailwind CSS** — Utility-first styling framework
- **Framer Motion** — React animations
- **shadcn/ui** — Beautiful prebuilt components
- **React Icons** — Icon support (e.g. GitHub, LinkedIn)

## 📦 Installation

**Clone the repository:**

```bash
git clone https://github.com/yourusername/eldar_portifolio.git
cd eldar_portifolio

- Install dependencies: `npm install`
- Run the development server: `npm run dev`
- Open http://localhost:3000 to see the portfolio live.
